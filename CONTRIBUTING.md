# Contributing

## Running Tests

```bash
cd /path/to/ehs-risk-sem
python3 -m unittest discover -s tests -v
```

108 tests, standard library only for core code and tests.

## Dependency Policy

This project uses Python 3.9 or later with:
- Standard library only (linalg, special, measurement, structural, model, identification, fit_indices, diagnostics, calibration, glm, rare_events modules)
- numpy (required for the montecarlo module only; optional for calibration.py which can do logistic regression)
- pandas (required for DataFrame results and examples)

No scipy, no statsmodels, no sklearn. The special module implements gamma, chi-square, normal CDF/quantile, and noncentral chi-square without scipy.

## Numbers in the Repository

Every number published in the README or in `results/` comes from committed scripts:

1. `python3 simulations/run_all.py --quick` generates `results_quick/` (fast, ~16 sec)
2. `python3 simulations/run_all.py` generates `results/` (full, ~11.5 minutes)
3. Results tables are committed so output can be read without re-running

All simulation parameters and data-generation code are visible in `simulations/` and every table is reproducible.

The MacCallum et al. (1996) power table comparison in Study 1 is pinned against the published article in `tests/test_maccallum_1996_tables.py` - all 284 cells are committed and re-checked on every run.

## Synthetic Data

`synthetic/` contains three generated datasets for simulation studies. Rules:

- Each CSV opens with `#`-prefixed lines stating it is synthetic, naming the generating model and parameters
- Files are regenerated by `python3 synthetic/generate_synthetic_datasets.py` with a seed
- Synthetic data is only for testing the estimator against known parameters and validating simulation studies
- **No finding about real workplace injuries comes from these files.** Real empirical work belongs to OSHA ITA, BLS SOII, or MSHA data sources.
